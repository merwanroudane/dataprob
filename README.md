# تحضير البيانات وتنظيفها للتعلّم الآلي — منصّة تعليمية عربية

منصّة Streamlit تفاعلية تشرح **كل ما يحدث قبل `model.fit`**: مشاكل البيانات
وأنواعها، وطرق تشخيصها ومعالجتها، وأثر كل قرار على البيانات وعلى الخوارزميات.

- **الشرح بالعربية، المصطلحات بالإنجليزية** (كما في التوثيق والأدبيات).
- **لكل درس خمسة تبويبات:** النظرية ← التطبيق بالبايثون ← أنيميشن تفاعلي
  (بزر تشغيل) ← جدول القرار «متى نفعل ماذا» ← المصادر الرسمية.
- **الشريط الجانبي على اليمين** وواجهة RTL كاملة، بألوان فاتحة متنوّعة.
- **موجّهة للمبتدئين**: لا تفترض أي خلفية سابقة في تحضير البيانات.

## التشغيل

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

ثم افتح <http://localhost:8501>.

## محتوى المنصّة (٢٦ درسًا في ٨ أقسام)

| القسم | الدروس |
|---|---|
| **ابدأ من هنا** | الصفحة الرئيسية · خريطة الطريق الكاملة · أنواع البيانات ومستويات القياس · فحص جودة البيانات |
| **القيم المفقودة** | أنواع الفقد (MCAR/MAR/MNAR) · التشخيص والاختبارات · الحذف · التعويض · الأثر على الخوارزميات |
| **القيم الشاذة** | الأنواع · الكشف أحادي المتغيّر · الكشف متعدّد المتغيّرات · المعالجة والقرار |
| **التكرار والتناسق** | القيم المكرّرة · توحيد الصيغ والأنواع |
| **التحويلات** | التقييس · تحويل التوزيعات والتجزيء · ترميز المتغيّرات الفئوية |
| **هندسة المتغيّرات** | هندسة المتغيّرات · اختيار المتغيّرات · تقليل الأبعاد (PCA) |
| **ما قبل النموذج** | عدم توازن الفئات · تسريب البيانات والتقسيم · بناء Pipeline كامل |

## بنية المشروع

```
streamlit_app.py        نقطة الدخول: التنقّل وحقن RTL
.streamlit/config.toml  الثيم: ألوان فاتحة متنوّعة + خط Cairo
core/
  rtl.py                CSS الوحيد في المشروع: اتجاه RTL وشريط جانبي يمين
  ui.py                 عناصر الدرس الموحّدة (بطاقات، جداول قرار، مصطلحات)
  anim.py               محرّك الأنيميشن: تشغيل/إيقاف/السابق/التالي عبر st.fragment
  charts.py             دوال رسم Altair مختصرة
  datasets.py           بيانات مُصنّعة مُخزّنة مؤقتًا (نعرف «حقيقتها» سلفًا)
app_pages/              ٢٦ درسًا، ملف لكل درس
```

## ملاحظات تصميمية

- **كل الأمثلة على بيانات مُصنّعة عمدًا.** فقط حين نعرف القيمة الحقيقية
  لكل خلية حذفناها أو شوّهناها نستطيع قياس خطأ كل معالجة بدقّة.
- **الرسوم بعناوين إنجليزية** لأن محرّك Vega-Lite لا يضمن تشكيل الحروف
  العربية داخل الرسم؛ الشرح العربي يوضع دائمًا حول الرسم.
- **CSS مخصّص في ملف واحد فقط** (`core/rtl.py`) لأن Streamlit لا يوفّر
  خيارًا أصليًا لقلب اتجاه الواجهة. كل الألوان والخطوط عبر `config.toml`.
- التجارب الحسابية مُخزّنة بـ `st.cache_data`، فالتشغيل الأول لبعض الصفحات
  يستغرق ثوانٍ ثم يصبح فوريًا.
